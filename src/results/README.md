# Results

- `CVE-2024-4340/` contains the reproduction run shown in the paper (Figure 2)
- `reproduced_cves/` contains the reproduction runs of all successfully reproduced CVEs in large scale study (Section 4.4)
- `analysis_stats.ipynb` notebook contains statistical analysis of reproduction runs in large scale study
- `project_types.json` contains the classification of projects

The results for all experiments in Section 3.5 and Section 4 are available [here](https://osf.io/dcej4/?view_only=81309bbc7e8c489abb9fb7e40bd1c0fb)

- `critics_evals.tar.gz` contains results for selecting LLMs and prompts (Section 3.5)
- `baseline.tar.gz` contains results for baseline assessment (Section 4.1)
- `design_ablation.tar.gz` contains results for cve-genie design ablations (Section 4.2)
- `robustness.tar.gz` contains results for cve-genie robustness to loss of cve context (Section 4.3)
- `large_scale.tar.gz` contains results for large scale study (Section 4.4)
